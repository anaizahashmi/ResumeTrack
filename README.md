# ResumeTrack.io - Multi-Page Resume & Application Tracking Website

A modern, responsive, multi-page **Website Platform** built with **React.js, JavaScript, HTML5, CSS3, and Tailwind CSS**.

---

## 🌐 3-Page Website Structure

1. **Page 1: Landing Page (`landing`)**:
   - Modern Public Homepage with Hero banner, value propositions, and CTA buttons (*"Get Started Free"*, *"User Login / Demo"*).
   - Supported Job Portals ticker (**LinkedIn**, **Naukri.com**, **Indeed**, **Internshala**, **Glassdoor**, **Wellfound**, **Career Portals**).
   - Core feature cards and 3-step workflow guide.
   - Interactive FAQ accordions and footer.

2. **Page 2: Login & Sign Up Page (`login`)**:
   - Clean Authentication Screen with Sign In and Create Account modes.
   - **Instant 1-Click Demo Login** button for immediate testing.
   - *"Back to Landing Page"* navigation.

3. **Page 3: Actual Resume & Application Management Portal (`dashboard`)**:
   - Authenticated user workspace header with profile info, theme toggle, and logout button.
   - **Resume Cards with Expandable Company Dropdowns**:
     - Click any resume to expand the company history dropdown.
     - Displays all companies applied with that specific CV.
     - Tracks **Date Applied** (with relative duration like *"3 days ago"*), **Online Portal Badges** (**LinkedIn**, **Naukri**, **Indeed**, **Internshala**, etc.), **Role**, and **Status**.
     - Direct **"+ Log Application"** button right inside the dropdown.
   - **Real-Time Modular Resume Editor**: Edit summaries, skills (Frontend, Backend, Tools), work history with bullets, education, and projects.
   - **A4 Printable Resume Preview Modal**: Instant **"Print / Save as PDF"** for clean A4 formatting.
   - **All Applications Master Table**: Filterable spreadsheet with **1-click CSV Export**.
   - **Analytics Dashboard**: Breakdown of applications by online portal and callback rates.
   - **Data Backup & Restore Modal**: Export/import JSON backups.

---

## How to Run the Website

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in Google Chrome, Microsoft Edge, Firefox, or another modern web browser.
4. The website runs directly in the browser and does not require a local server or Node.js installation.
